# PPZ Generator

Генератор уровней для PathPix: изображение → головоломка в формате `.ppz` с
гарантией (или проверкой) единственного решения. Формат описан в `ppz-format.md`,
просмотр готовых уровней — `ppz-viewer.html`.

## Установка

```bash
pip install pillow            # обязательно
pip install python-sat        # рекомендуется: быстрая проверка единственности
```

Нужны два файла рядом: `ppz_gen.py` (генератор) и `ppz_sat.py` (SAT-солвер,
подхватывается автоматически при наличии `python-sat`).

## Быстрый старт

```bash
# минимум: вход и выход, остальное — авто
python ppz_gen.py photo.png level.ppz

# полный цикл с контролем результата
python ppz_gen.py photo.png level.ppz --time 60 --preview level.png --palette-out palette.png
```

## Параметры

### Позиционные
| Параметр | Назначение |
|---|---|
| `input` | входное изображение (PNG/JPEG/любой формат Pillow) |
| `output` | путь к `.ppz` |

### Основные
| Параметр | По умолчанию | Назначение |
|---|---|---|
| `--max N` | 150 | максимальный размер сетки по длинной стороне |
| `--colors N` | авто (10) | запрос цветов квантования (лимит формата — 30) |
| `--merge-thresh N` | 24 | слияние визуально одинаковых цветов после квантования: JPEG-шум раскалывает плоские заливки на микро-цвета → лавина одиночных квадратиков. 0 = отключить; чистые PNG — 16–24, зашумленные JPEG — 32–40 |
| `--target N` | авто 5/6/7 | желаемая длина пути; каждая змейка получает ±30%; лимит формата — 31 |
| `--seed N` | 0 | затравка нарезки; главный инструмент перебора вариантов. Принимает целое число или `random` — тогда сид выбирается случайно и печатается в консоль (сохраните его для воспроизводимости) |
| `--bendiness 0..1` | авто (0.85) | извилистость змеек (эталон оригиналов ~0.46 поворота/клетку) |
| `--time СЕК` | 15 | лимит солвера: половина — ремонт, половина — финальная проверка |
| `--prewall-density 0..1` | 0.15 (SAT) / 1.0 (бэктрек) | доля параллельных контактов, застениваемых до ремонта. 0 = только доказанно нужные стены (медленнее, стен меньше); выше 0.3 — быстрее, но стен больше |
| `--try-seeds N` | 1 | перебор сидов: взять первый, где решение единственно **совсем без стен** (как в оригиналах); кандидаты оцениваются с нулевыми стенами. Если ни один не подошёл — пре-воллинг + ремонт лучшего. На мелких полях попытка — доли секунды |
| `--preview FILE` | — | картинка уровня: подсказки, квадратики, стены |
| `--export-img BASE` | — | картинка уровня (квантованная): `BASE_4x.png` — ровно 4× от сетки (как в файлах игры) и `BASE_1x.png` — 1× (пиксели уровня без масштаба) |

### Проверка единственности
| Параметр | Назначение |
|---|---|
| `--solver auto` (умолч.) | SAT при наличии `python-sat`, иначе бэктрек |
| `--solver sat` | только SAT; ошибка, если библиотека не установлена |
| `--solver backtrack` | только бэктрек; поля >1500 клеток пропускаются |
| `--no-check` | не проверять единственность |
| `--safe-walls` | единственность по построению: стены на всех одноцветных контактах |

### Прочее
| Параметр | Назначение |
|---|---|
| `--quiet` | без вывода этапов `[1/5]…[5/5]` |

## Как ставятся стены

1. **Пре-воллинг** (до солвера): разреженные стены на параллельных контактах
   крупных цветов (как в оригиналах ~15%). Плотность: 15% с SAT, 100% с бэктреком.
2. **Ремонт** (на этапе проверки): солвер находит альтернативное решение → стена
   встаёт ровно на его отклонение от канона. Целенаправленно, не случайно.
3. **safe-walls**: все контакты одноцветных путей (тяжело выглядит, зато мгновенно).

## Типовые сценарии

```bash
# черновик, скорость важнее гарантий
python ppz_gen.py sketch.png draft.ppz --no-check --preview draft.png

# боевой уровень с подтверждением
python ppz_gen.py cat.png cat.ppz --time 60 --palette-out cat-4x.png

# перебор однозначного варианта (cmd.exe)
for %s in (0 1 2 3 4) do python ppz_gen.py cat.png cat%s.ppz --seed %s --time 45

# одна прогонка со случайным сидом (сид напечатается в консоль)
python ppz_gen.py cat.png cat.ppz --seed random

# уровень без единой «ремонтной» стены: перебор сидов (cmd.exe)
python ppz_gen.py medal.png medal.ppz --try-seeds 30 --time 20

# большая заливочная картинка, гарантия без ожидания
python ppz_gen.py poster.png poster.ppz --safe-walls

# точная настройка стиля
python ppz_gen.py icon.png icon.ppz --target 8 --bendiness 0.95 --colors 6
```

## Статусы на этапе [3/5]

| Статус | Значение |
|---|---|
| `единственное решение` | солвер подтвердил — уровень готов |
| `НЕ ЕДИНСТВЕННО` | найдено другое решение; меняйте `--seed` или берите `--safe-walls` |
| `не подтверждено (лимит времени)` | лимит `--time` исчерпан; поднимите или переберите seed |

Этап `[5/5]` — независимая проверка самого файла (формат, пути, стены, контрольная
сумма); она проходит всегда и не зависит от статуса единственности.

## Ограничения формата

- путь ≤ 31 клетки (5-битная подсказка), цветов ≤ 30;
- солвер: SAT — поля любого размера в пределах `--time`; бэктрек — до ~1500 клеток;
- на больших однородных заливках однозначность без `--safe-walls` может не
  подтвердиться за разумное время — это свойство задачи, а не баг.
