PPZ Viewer

Визуальный просмотр уровней PathPix (файлы .ppz): загадка, решение из стрелок, стены и проверка целостности.
demo: 001.ppz
перетащите .ppz файл в область выше или нажмите «открыть»
Формат: заголовок PPZ  + версии + размер тела; тело v1 — размеры, палитра ARGB, затем по 3 байта на клетку (row-major): цвет (5 бит), стрелки (3+3 бита, коды 1=W,2=N,3=E,4=S), подсказка (5 бит: 0 — путь, 1 — квадратик, иначе длина пути), маска стен (W=1,N=2,E=4,S=8).
