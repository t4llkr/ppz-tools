PPZ Viewer

Визуальный просмотр уровней PathPix (файлы .ppz): загадка, решение из стрелок, стены и проверка целостности.
demo: 001.ppz
перетащите .ppz файл в область выше или нажмите «открыть»
Формат: заголовок PPZ  + версии + размер тела; тело v1 — размеры, палитра ARGB, затем по 3 байта на клетку (row-major): цвет (5 бит), стрелки (3+3 бита, коды 1=W,2=N,3=E,4=S), подсказка (5 бит: 0 — путь, 1 — квадратик, иначе длина пути), маска стен (W=1,N=2,E=4,S=8).
Режим «Решать»: тяните путь от подсказки (или от конца уже нарисованного пути); шаг назад по своему пути стирает его край. Соедините две одинаковые подсказки одного цвета ровно указанным числом клеток; клетка не может принадлежать двум путям. Дабл-клик по пути стирает его целиком. Кнопка «Проверить» сверяет все проложенные пути с единственным решением уровня и очищает несовпавшие.
